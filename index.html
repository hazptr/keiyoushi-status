keiyoushi extension status

Weekly automated check of every keiyoushi 1.6 extension, built from main. Unofficial; not affiliated with keiyoushi.

What is checked

Each extension's real code runs on a JVM harness (no phone): Popular page 1, then details and chapter list of a popular entry, then that chapter's page list, then two page images are downloaded through the extension's own HTTP client and decoded. A failure is retried before it counts.

Untestable means the harness couldn't get a result for reasons that don't say the extension is broken: a Cloudflare challenge it can't solve (the app solves those in a WebView or asks you to), a build or harness error, or a timeout. Check those in the app.

1.4 extensions aren't covered. Results reflect main at the commit shown, which can be ahead of the published APKs.
